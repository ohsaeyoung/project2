# 🏠 이사 정산 도우미 (Electric & City Gas Move Settlement Helper)

> **대한민국 이사 당일 전기요금(한국전력) 및 전국 34개 도시가스사 요금 조회·정산 원스톱 안내 웹 애플리케이션**

---

## 📌 1. 서비스 개요 및 목적

- **서비스명**: **이사 정산 도우미**
- **목적**: 
  - 이사 당일 분산된 전기 및 도시가스 정산에 필요한 필수 정보(고객번호, 계량기 지침, 이사일자)를 한곳에서 체계적으로 관리
  - 입력된 주소(시·도 및 시·군·구)를 바탕으로 관할 도시가스사를 100% 자동 식별하고 전출 방문 예약 및 공식 조회 경로 안내
  - 공식 API 연동 시 실시간 요금 조회, 미연동 시 원칙에 따라 투명하게 **'실시간 조회 미연결'** 상태를 표시하고 공식 창구(한전ON, 관할 가스사)로 안전하게 연결
  - 이사 전(D-7), 이사 당일(D-Day), 이사 후 단계별 체크리스트를 브라우저 로컬 저장소에 영속 관리하여 누락 방지

---

## 🛡️ 2. 핵심 개발 원칙 준수 현황

1. **임의 요금 생성 금지**: 실제 전기요금과 도시가스 요금을 임의로 가공하여 실시간 조회 결과처럼 속이지 않습니다.
2. **명확한 연결 상태 표시**: 공식 API 연동 여부(`isConnected: false`)를 화면 상단 및 결과 카드에 명확한 뱃지로 표시합니다.
3. **공식 사이트 및 수동 정산 안내**: 미연결 상태일 경우 한국전력(한전ON, 123) 및 관할 도시가스사의 검증된 공식 사이트 및 고객센터로 직접 안내합니다.
4. **참고용 예상 금액 투명성**: 계량기 지침 기반 계산기는 실제 청구서가 아닌 '참고용 예상 금액'으로 구분하며, 누진 단계 요율 근거 및 '공식 정산 금액과 다를 수 있음' 안내를 명시합니다.
5. **완료 상태 오표시 방지**: 단순히 공식 사이트를 새 창으로 열었다고 해서 정산이 완료된 것으로 자동 전환하지 않으며, 사용자가 공식 결제 및 영수증 확인 후 직접 '정산 완료 확인'을 체크할 수 있도록 통제권을 부여합니다.
6. **민감정보 보호**: 주민등록번호나 계좌번호 등 불필요한 개인정보를 수집하지 않으며, API 키는 `.env` 환경변수로만 관리됩니다.

## 📑 3. 페이지 구성

| 페이지 | 역할 및 주요 기능 |
|:---|:---|
| **페이지 A. 메인 홈페이지** | 서비스 헤더, 메인 문구, 정산 시작하기 & 체크리스트 빠른 시작, 전기/도시가스 조회 요약 카드, 4단계 절차 가이드 |
| **페이지 B. 이사 정보 입력** | 필수 항목(이사유형, 날짜, 주소, 주거형태) 및 선택 항목(전기/가스 고객번호, 계량기 지침, 사진 첨부), 관할 가스사 자동 식별 |
| **페이지 C. 전기요금 조회** | 한국전력 주소지/이사일/고객번호 상태, 계량기 지침, 실시간 연동 상태, 123 전화 vs 한전ON 웹 vs 관리사무소 정산 비교 |
| **페이지 D. 도시가스 요금 조회** | 전국 34개사 지역 독점 매핑, 가스레인지 철거 시 안전마개 봉인 시공을 위한 **전출 방문 예약(D-3) 필수 안내**, 고객센터 직통 연결 |
| **페이지 E. 통합 정산 대시보드** | 전기와 가스 상태를 7가지 상태 뱃지(정보 미입력, 입력 완료, 공식 사이트 확인 필요, 조회 진행 중, 조회 성공, 실패, 정산 완료 확인)로 통합 표시, 인쇄 기능 |
| **페이지 F. 이사 체크리스트** | 이사 전 / 당일 / 후 총 14개 단계별 체크 항목, 진행률 바(%), 로컬스토리지 자동 저장 및 복원, 미완료 필터, 인쇄 및 초기화 |

## 🛠️ 4. 기술 스택 & 시스템 아키텍처

- **프론트엔드**: React 19, TypeScript, Tailwind CSS v4, Lucide React (접근성 고려 공공서비스형 단정하고 신뢰감 있는 디자인)
- **백엔드 (API 레이어)**: Node.js (v24), Express 5, CORS, Dotenv
- **데이터 레이어**:
  - `server/data/gasProviders.js`: 대한민국 전국 34개 도시가스사 지역 매핑 DB
  - `server/services/electricityService.js`: 한전 API 연동 인터페이스 및 샌드박스
  - `server/services/gasService.js`: 도시가스 사업자 API 연동 인터페이스
- **클라이언트 스토리지**: HTML5 LocalStorage (체크리스트 진행상황 및 입력폼 임시 캐시)

## 🚀 5. 실행 및 개발 방법

### 1) 의존성 설치
```bash
npm install
```

### 2) 백엔드 및 프론트엔드 동시 실행
```bash
npm run dev:all
```
- 백엔드 API 서버: `http://localhost:3001`
- 프론트엔드 웹 UI: `http://localhost:5173`

> 백엔드만 별도 실행: `npm run server`  
> 프론트엔드만 별도 실행: `npm run dev`

### 3) 프로덕션 빌드 & 검증
```bash
npm run build
```

## ⚙️ 6. 환경변수 설정 예시 (`.env`)

프로젝트 루트의 `.env` 또는 `.env.example`을 참조하여 설정합니다:

```env
# 백엔드 서버 포트
PORT=3001

# 한국전력공사 (KEPCO) OpenAPI 인증키 (공공데이터포털 또는 한전 데이터마켓)
KEPCO_API_KEY=
KEPCO_API_ENDPOINT=https://api.kepco.co.kr/v1

# 전국 도시가스사 전자청구/정산 API 키
CITYGAS_API_KEY=
CITYGAS_API_ENDPOINT=

# 개발/검증용 시뮬레이션 모드 (기본 false: 엄격한 미연결 원칙 준수)
ENABLE_KEPCO_MOCK=false
ENABLE_GAS_MOCK=false
```

## 📋 7. 실제 API 연동에 필요한 추가 작업 목록

실제 한국전력 및 도시가스 사업자와 실시간 연동을 진행할 때 필요한 절차는 다음과 같습니다.

### A. 한국전력공사 (전기)
1. **공공데이터포털 또는 한전ON 비즈포털 기업회원 가입 및 API 활용신청**
   - 제공 API: 전기요금 청구/수납 내역 조회, 이사정산 요금 산출 API
2. **고객 동의 및 본인인증 체계 연계**
   - 전기요금은 개인정보보호법상 고객번호 단독 조회 외에 명의자 본인인증(PASS, 공동인증서, 카카오인증 등) 또는 고객번호와 고객 성명 일치 검증 절차 구현
3. **가상계좌 발급 및 PG 연동 승인**
   - 당일 요금 납부를 위한 전용 일회용 가상계좌 채번 인터페이스 계약

### B. 전국 도시가스 사업자
1. **지역별 34개 도시가스사 또는 한국도시가스협회와의 B2B 제휴**
   - 서울도시가스(서울/경기북부), 삼천리(경기남부/인천), 코원에너지(서울강남/경기동부), 예스코(서울강북/경기동북부) 등 대형 공급사 EDI 연동
2. **전출 방문 예약 웹훅/API 연계**
   - 사용자가 사이트에서 날짜/시간을 선택하면 해당 도시가스사 기사 배정 시스템에 자동 인입되는 전출 접수 인터페이스 계약
3. **카카오페이 청구서 / 토스 공과금 연동 모델 검토**
   - 개별 도시가스사 API 계약이 어려울 경우 핀테크 공과금 조회 Aggregator API와의 제휴 검토
